# Vanshika - Personal Portfolio

A simple and responsive personal portfolio website built using HTML and CSS.  
The website showcases my skills, projects and contact information.

## 🌐 About the Website

This portfolio website contains four main pages:

- **Home** – Introduction and basic information
- **About** – My skills and interests
- **Projects** – My projects and technologies used
- **Contact** – Contact form for visitors

## 🚀 Projects

### 1. AI Resume Analyzer
An AI-based project that analyzes resumes and provides insights about skills, experience and job suitability.

**Technologies:** Python, AI, Machine Learning

### 2. House Price Prediction
A machine learning project that predicts house prices based on different property-related features.

**Technologies:** Python, Pandas, NumPy, Scikit-learn

### 3. FlappyBot – Human vs AI
A Python-based Flappy Bird game with Human and AI modes. The AI uses a decision-making algorithm, and the project compares Human and AI performance using graphs.

**Technologies:** Python, Pygame, AI, Matplotlib
